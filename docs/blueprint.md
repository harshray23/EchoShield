# **App Name**: FireBase Explorer

## Core Features:

- Auth Simulation: Simulate user authentication flow with login and signup functionalities.
- Data Interface: Provide a data management interface to add, view, and manage 'documents'.
- Storage Simulator: Implement a file upload simulator for 'storage'.
- Console Dashboard: Develop a simplified console dashboard to visualize user interactions and data changes.

## Style Guidelines:

- Primary color: Dark blue (#2C3E50) for a modern, tech-inspired theme, drawing from the prompt's mention of blue accents. The serious nature of cloud services is part of this theme, too.
- Background color: Very dark gray (#1E293B) for a dark theme.
- Accent color: Red (#E74C3C) for interactive elements and highlights, aligning with the prompt's request for red accents, and chosen to offer a visual pop.
- Body font: 'Inter', a grotesque-style sans-serif, is used for its modern and neutral feel; headlines should also use this typeface.
- Use minimalist, line-style icons to represent different Firebase features, enhancing the modern aesthetic.
- Employ a grid-based layout to organize the dashboard and data interfaces, ensuring a clean and structured user experience.
- Incorporate subtle transition animations when navigating between sections or when data is updated to provide smooth user experience.
